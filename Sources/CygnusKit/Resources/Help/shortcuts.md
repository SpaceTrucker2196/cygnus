# Menus and Shortcuts

## Text size

App-wide text size scales every semantic text style, and the setting
persists across launches. The graph's own node labels have a separate
**Label size** slider in the graph controls, so you can enlarge the
interface without enlarging the graph, or the reverse.

- **Bigger Text** — Command and =
- **Bigger Text** — Command, Shift and + (the same action; a
  Command-only shortcut cannot match a literal "+", which needs Shift)
- **Smaller Text** — Command and -
- **Reset Text Size** — Command and 0

## Help

- **Cygnus Help** — Command and ? opens this reference.

## Graph gestures

- **Click** a node to focus it; **click** empty space to clear.
- **Double-click** to reset zoom and pan.
- **Drag** to pan, **pinch** to zoom.
- **Click** a legend group to explode it.

In CI Flow, **scroll** zooms and **drag** pans.

## Accessibility

The graph canvas is opaque to VoiceOver by nature, so it is presented
as a single element with a spoken summary — node, edge, and cycle
counts, plus the current selection — and an interaction hint. Sliders,
pickers, and toggles announce their values; sidebar rows read the
repository name and analysis state; the memory meter reads its usage
and pressure.
